# 해설 작성 규약 (집필자용)

`data/explanations/<round>.json` 한 회차 = 한 파일. 자기 담당 회차 파일과 `PROGRESS.md` 의 **자기 행만** 고친다.
**`data/rounds/*.json` 은 감사 완료 자산이므로 절대 수정 금지.**

## 파일 형태 (동결)

```json
{
  "round": "2020-1",
  "explanations": {
    "2020-1#1": "<p>정답은 <mark>…</mark>입니다.</p><p>…</p>",
    "2020-1#2": "…",
    "2020-1#20": "…"
  }
}
```

- UTF-8. 최상위 `round` 는 **파일명과 같아야** 한다.
- 그 회차의 **모든 문항 id 를 정확히** 커버한다 — 누락도 잉여도 실패다(현재 전 회차 20문항, 제외 문항 없음).

## 마크업 규칙 (검증기가 강제한다)

| 항목 | 규칙 |
|---|---|
| 허용 태그 | `p` `b` `mark` `br` `ul` `ol` `li` `code` `pre` **만** |
| 속성 | **전면 금지** — `<p class="x">` 는 실패 |
| 길이 | **150~1500자** (태그 포함) |
| 이스케이프 | 코드·수식의 `<` `>` `&` 는 반드시 `&lt;` `&gt;` `&amp;` 로. 태그가 아닌 날 `<` 는 실패 |
| 금지 | `<script`, `javascript:` — 즉시 실패 |

## 작성 지침

**독자는 비전공자다.** 용어는 풀어 쓰고, 한 줄 비유나 예시를 곁들인다. 존댓말 평서문으로 쓴다.

권장 구조:

1. **정답 제시** — 무엇이 답인지 먼저 말한다.
2. **핵심 개념을 쉬운 말로** — 용어 정의 + 비유 한 줄.
3. **왜 이 답인지** — 문제의 어느 단서가 그 답을 가리키는지.
4. **코드·계산 문제는 단계별 추적** — `<ul><li>` 또는 `<br>` 로 한 줄씩.
5. **헷갈리는 이웃 개념과의 구별** 한 줄.

강조:

- 핵심 **용어**는 `<b>`.
- 꼭 기억할 문장·정답 포인트는 `<mark>` — **문항당 1~3개**. 남발하면 강조가 죽는다.

**사실 근거 (가장 중요)**

- 반드시 그 문항의 `fields[].accept` / `fields[].sampleAnswer` / `display` / `bodyText` 를 읽고
  **실제 정답과 일치하게** 쓴다. 해설이 정답과 어긋나는 것이 이 작업의 최대 리스크다.
- **코드 출력·계산 문제는 직접 손으로 실행·계산해 검산한 뒤** 서술한다.
- 서술형(`keywords` validator)은 모범답안(`display`)을 중심으로 개념을 설명한다.

해설은 **채점이 끝난 뒤에만** 노출되므로 정답을 그대로 말해도 된다 — 오히려 그래야 한다.

## 체크포인트 (세션 유실 대비 — 필수)

회차 하나를 끝낼 때마다:

```bash
node scripts/validate-explanations.mjs --partial   # 존재하는 파일만 검사
```

통과하면 `data/explanations/PROGRESS.md` 의 자기 행을 `완료` 로 바꾸고 다음 회차로 넘어간다.
전 회차가 끝나면 `npm run validate:explain` (전체 모드)가 통과해야 한다.

## 예시 (형태 참고용 — 실제 문항 해설 아님)

```json
"2020-1#1": "<p>정답은 <mark>내용 결합도</mark>입니다.</p><p><b>결합도</b>는 두 모듈이 서로 얼마나 얽혀 있는지를 나타내는 척도입니다. 옆집과 벽 하나를 공유하는 정도라면 약한 결합이고, 아예 남의 집 안방을 마음대로 드나든다면 강한 결합입니다.</p><p>문제의 설명처럼 <b>한 모듈이 다른 모듈의 내부 기능이나 자료를 직접 참조·변경</b>하는 경우가 가장 강한 결합이며, 이를 내용 결합도라고 부릅니다.</p><ul><li>공통 결합도: 전역 변수를 함께 쓰는 경우 — 내부를 직접 건드리지는 않습니다.</li><li>스탬프 결합도: 자료 구조 전체를 넘기는 경우입니다.</li></ul>"
```
