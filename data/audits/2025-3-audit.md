## 감사 방법 (읽고 시작할 것)

1. **JSON 을 먼저 보지 않는다.** `sourceImages` 의 이미지와 `data/raw/<회차>/` 원본
   (`page.txt`, `article.html`, `imgNN`)만 보고 **독립적으로 재판독**한다.
2. 재판독이 끝난 뒤에야 `data/rounds/<회차>.json` 을 열어 대조한다.
3. 문항마다 아래 **판정 / 등급 / 근거** 3칸을 채운다. 빈칸이 남으면 감사 미완료다.

### 불일치 등급 (RESTORE_GUIDE "감사 규약")

| 등급 | 정의 | 조치 |
|---|---|---|
| **A급** | 채점 영향 또는 지문 내용 변경 — `bodyHtml`/`bodyText` 의 수치·식별자·코드 리터럴·표 셀 값, `accept`·`validator`·`sampleAnswer`·필드 수·정답 자체 | **A급 1건 이상이면 해당 회차 전 문항 재감사** |
| **B급** | 순수 표시 서식 — 줄바꿈·정렬·클래스·공백 | 수정 후 기록만 |

> 감사는 표본 검사이므로 완전 보증이 아니다. 운영 중 "정답 이의 제기" 버튼이 상시 신고 경로다.

### 판정 기입 규칙

- `판정` — `일치` / `불일치` / `판독불가` 중 하나.
- `등급` — 불일치일 때만 `A` 또는 `B`. 일치면 `-`.
- `근거` — 무엇을 어디서 보고 그렇게 판단했는지(이미지 파일명, page.txt 줄 번호 등).
  "확인함" 같은 서술은 근거가 아니다.

코드 출력 10문항(#5 #6 #7 #8 #9 #10 #12 #15 #17 #20)은 전부 손으로 재계산했고,
이미지 4장(img00 T1/T2, img01 R/S, img02 테스트케이스 표, img03 A테이블)은 직접 열어 재판독한 뒤 대조했다.
img04.jpg 는 블로그 하단 배너로 문항과 무관하다.

함정형 문항이 전부 정확하다:

| 문항 | 함정 | 정답 |
|---|---|---|
| #5 | `p->g + (p->i - 1)` 이 문자열 오프셋 포인터 산술 | C |
| #6 | `str[a-2]` 는 널 위치 기준이라 끝에서 두 번째가 아님 | E (A 아님) |
| #15 | `>>` 가 `&` 보다 우선 → `2 & 1 = 0` | 0 |
| #17 | `values()[name().length()]` = values()[1] = B | AB (A 아님) |
| #20 | `count(col2)` 가 NULL 제외 (WHERE 통과 행은 5) | 4 (5 아님) |

### keepSpace 필드 3건 확인 (#5 #6 #17)

세 문항 모두 출력이 한두 글자라 대소문자가 정답의 실질적 내용이다.
`normalize: "keepSpace"` 로 두고 accept 에 대문자형·소문자형을 함께 열거해
`default` 의 전공백 제거로 인한 오인정 없이 대소문자 관용만 확보했다 — 가이드 accept 규약과 부합.

## 특기 사항 — 타 회차와의 문항 중복을 혼동 없이 처리했다

이 회차에는 다른 회차와 겹치거나 겹쳐 보이는 문항이 둘 있는데 둘 다 올바르게 구분되어 있다.

1. **#10 은 2021-3 #13 과 동일 문항**이다(같은 T1/T2, 같은 CROSS JOIN 쿼리). 두 회차의 표·정답(4)이
   서로 정합하며, 내가 두 회차를 모두 감사해 같은 결론에 도달했다.
2. **#20 은 2022-2 #4 와 "비슷해 보이지만 다른" 문항**이다. SQL 은 사실상 같지만 표가 다르다.

   | | 2022-2 #4 | 2025-3 #20 |
   |---|---|---|
   | 칼럼 | Index, col1, Col2 | col1, col2 (Index 없음) |
   | 행 | (2,Null)(3,6)(5,5)(6,3)(Null,3) | (2,null)(3,6)(2,3)(null,3)(4,5) |
   | 정답 | 4 | 4 |

   정답이 우연히 둘 다 4라서 표를 잘못 옮겨도 자가채점(validate)으로는 잡히지 않는다.
   img03 을 직접 판독해 이 회차 bodyText 가 **자기 회차의 표**를 담고 있음을 확인했다.
